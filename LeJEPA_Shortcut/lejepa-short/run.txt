### hyperparams

## Adaptive Regularization
adaptive_lambda
    [FLOAT value 0.0 ~ 1.0 or omit (blank)]
    SIGReg Strength for adaptive lambdas.
    This also works as ON/OFF button for adaptive lambda regularization
    Also this is for the onlline regularization, NOT for pretrained-adaptive-lambdas
    
top_k
    [INT value 1 ~ 20 or omit (blank)]
    Using only top k adaptive lambdas for the upper regularization
    Used only if the above adaptive_lambda is ON


## Clean-only dataset
clean_pretrain
    [BOOLEAN: True/False or omit (blank)]
    True if pretrain with clean data
    False (or omit) if pretrain with patched(colored) data


## Stepwise variances
basis_path 
    [STRING path to the basis file or omit (blank)]
    Used for checking pretrained eigenvectors,
    to check the variances of those vectors
    [May not be used due to its poor performance]
