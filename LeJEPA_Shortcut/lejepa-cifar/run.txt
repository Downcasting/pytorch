### hyperparams

## Small Initialization
    small_init_alpha
        [FLOAT value 0.0 ~ 1.0 or omit (blank)]
        Small Initialization Strength for the model weights.
        This is for the stepwise nature of SSL, not for the adaptive lambda regularization.
        Used only if the above adaptive_lambda is OFF


## Clean-only dataset
    clean_pretrain
        [BOOLEAN: True/False or omit (blank)]
        True if pretrain with clean data
        False (or omit) if pretrain with patched(colored) data


## Stepwise variances
    basis_path 
        [STRING path to the basis file or omit (blank)]
        Used for checking pretrained eigenvectors,
        to check the variances of those vectors
        [May not be used due to its poor performance]


## Null it out method
    null_it_out
        [BOOLEAN: True/False or omit (blank)]
        True if you want to use null it out method
        False (or omit) if not

    null_start_epoch
        [INT value 1~ or omit (blank), 50 recommended]
        Number of epochs to start null it out method
        Used only if the above null_it_out is ON

    null_every_epoch
        [INT value 1~ or omit (blank), 20 recommended]
        Number of epochs to update null space
        Used only if the above null_it_out is ON

    null_dim_start
        [INT value 0~ or omit (blank), 1 recommended]
        Start dimension to nullify
        Used only if the above null_it_out is ON

    null_dim_end
        [INT value ~16 or omit (blank), 4 recommended]
        End dimension to nullify
        Used only if the above null_it_out is ON
